# Project 21 - CloudWatch Monitoring Dashboard

## Objective

Create a CloudWatch Dashboard to visualize Amazon EC2 performance metrics and monitor infrastructure health.

## Services Used

- Amazon EC2
- Amazon CloudWatch

## Project Overview

This project demonstrates infrastructure monitoring using Amazon CloudWatch Dashboards. A custom dashboard was created to visualize key EC2 performance and health metrics.

## Activities Performed

- Selected an EC2 instance for monitoring.
- Created a CloudWatch Dashboard.
- Added multiple monitoring widgets.
- Visualized performance metrics.
- Verified dashboard functionality.
