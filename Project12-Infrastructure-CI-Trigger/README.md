# Project 12 - Infrastructure CI Trigger (Terraform Plan)

## Objective

Implement a CI pipeline that automatically executes Terraform Plan and stores the generated plan file as a pipeline artifact.

## Activities Performed

- Created a GitHub Actions workflow.
- Triggered Terraform Plan on every push.
- Generated Terraform execution plan.
- Uploaded the generated plan as a workflow artifact.

## Workflow Steps

- Terraform Init
- Terraform Plan
- Upload Plan Artifact

## Deliverable

- Successful pipeline execution screenshot
- Uploaded artifact screenshot

## Result

Successfully automated Terraform planning and artifact generation using GitHub Actions.
