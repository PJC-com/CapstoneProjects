# Project 5 - Secure Linux Server Permissions

## Objective

Apply user-based access restrictions using Linux users, groups, and file permissions.

## Activities Performed

- Created developers group
- Created users alice and bob
- Added alice to developers group
- Created protected directory
- Configured file permissions
- Validated allowed and denied access

## Test Results

### Allowed Access
alice successfully accessed and modified project.txt.

### Denied Access
bob was denied access to project.txt.

## Result

Successfully implemented user-based access control using Linux permissions.
