# Project 1 - Deploy a Linux EC2 Web Server Using Terraform

## Objective
Deploy a Linux EC2 instance using Terraform and host a web page through Apache.

## AWS Services Used
- EC2
- VPC
- Internet Gateway
- Route Table
- Security Group

## Terraform Commands Used

terraform init

terraform validate

terraform plan

terraform apply

## Outputs
- EC2 Instance ID
- Public IP
- Website URL

## Result
Successfully deployed a web server accessible through the EC2 public IP.
